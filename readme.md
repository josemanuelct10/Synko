# Synko

Synko is an intelligent document management platform powered by Generative AI, semantic search, and RAG.

Synko es una plataforma inteligente de gestión documental basada en IA generativa, búsqueda semántica y RAG.

## Project Status

Early architecture and documentation phase.

## Tech Stack

- Angular 21
- Microfrontends
- Node.js
- Express
- TypeScript
- PostgreSQL
- Qdrant
- Docker
- Jenkins

## Initial Roadmap

1. Define project documentation.
2. Create base repository structure.
3. Configure backend with Express and TypeScript.
4. Configure Angular shell.
5. Add PostgreSQL and Qdrant with Docker Compose.
6. Implement authentication.
7. Implement document upload.
8. Implement embeddings and semantic search.
9. Build the initial RAG flow.
10. Add Jenkins pipeline.

## Purpose

This project is being built as a professional portfolio project to demonstrate backend architecture, frontend modularity, infrastructure automation, and applied Generative AI.
